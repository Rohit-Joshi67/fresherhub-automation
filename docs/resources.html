Curated interview checklists, syllabus breakdowns, and preparation roadmaps for private tech roles and central government exams.

SSC Exams: CGL & CHSL Preparation Central Govt

The Staff Selection Commission conducts Tier-I and Tier-II Computer-Based Tests (CBT) for central ministry appointments.

  • Quantitative Aptitude: Arithmetic (Percentages, Profit & Loss, Ratio & Proportion, Time-Work-Distance) and Advanced Math (Algebra, Geometry, Trigonometry, Mensuration).
  • General Intelligence & Reasoning: Analogies, Number series, Coding-Decoding, Syllogisms, Blood relations, Non-verbal pattern folding.
  • General Awareness: 6-month Current Affairs (schemes, appointments, summits), Indian Polity & Constitution, Modern Indian History, and Basic Science.
  • English Comprehension: Spotting the error, Cloze test, Active/Passive voice, Direct/Indirect speech, Reading comprehension.
  • Skill / Typing Test: Data Entry Operator (DEO) requires 8,000 key depressions/hour. Practice on official keyboard simulation tools.

Railway Recruitment Board (RRB JE & NTPC) Railways

RRB conducts national CBT examinations for Junior Engineer (IT/Technical) and Non-Technical Popular Categories.

  • CBT-1 (Screening): Mathematics (30 Qs), General Intelligence & Reasoning (25 Qs), General Science (Physics, Chemistry, Life Sciences - 30 Qs), General Awareness (15 Qs). Time: 90 Minutes.
  • CBT-2 Technical IT Syllabus: Operating Systems, DBMS (SQL & Relational Schema), Computer Networks (OSI & TCP/IP model), Object-Oriented Programming (C++/Java), and Web technologies.
  • Negative Marking: 1/3rd deduction for each incorrect answer — focus on precision over guesswork.

IBPS IT Specialist Officer (Scale I) Banking

Common recruitment process for IT Officers managing core banking infrastructure across nationalized banks.

  • Professional Knowledge (IT): Database Management (normalization, indexing, ACID properties), Computer Networking (routing protocols, subnets, firewalls), Data Structures, Software Engineering cycles, and Cyber Security fundamentals.
  • Preliminary Stage: Reasoning (50 Qs), English Language (50 Qs), Quantitative Aptitude (50 Qs). Total 150 Qs in 120 minutes with sectional cutoffs.
  • Mains & Interview: In-depth IT MCQs followed by technical and banking awareness interview panel.

NIC Scientist-B & Scientific Officer Govt Tech

Recruitment for entry-level computer science engineers designing e-governance systems for the Ministry of Electronics and IT.

  • Section A (Generic): Logical reasoning, quantitative analytical ability, and general mental ability (35% weightage).
  • Section B (Computer Science): Algorithms, discrete mathematics, compiler design, computer architecture, distributed systems, and web services (65% weightage).

Structured Query Language (SQL) Database

Essential for software engineering, analytics, and backend support interviews.

  • Aggregations & Grouping: Master GROUP BY, HAVING, and aggregate functions (SUM, AVG, COUNT(DISTINCT)).
  • Joins: Understand Cartesian products, difference between LEFT JOIN vs INNER JOIN, and filtering in the ON vs WHERE clause.
  • Window Functions: Frequently tested in tech screenings: ROW_NUMBER(), DENSE_RANK(), and cumulative partitioning.

Core Java & Object-Oriented Design Language

A primary interview staple across enterprise and product engineering hiring in India.

  • OOP Pillars: Real-world examples of Abstraction vs Encapsulation, Runtime Polymorphism, and Interface segregation.
  • Collections Framework: Internal working of HashMap, concurrency handling, and performance differences between ArrayList and LinkedList.
  • Memory Management: Stack vs Heap allocations, Garbage Collection basics, and string immutability.

Spring Boot & Microservices Backend

Framework expectations for entry-level Java backend developers.

  • Dependency Injection: Inversion of Control (IoC), @Autowired, @Component vs @Bean lifecycle.
  • REST APIs: HTTP methods (GET, POST, PUT, DELETE, PATCH), status codes, and exception handling using @ControllerAdvice.
  • Data Persistence: Spring Data JPA repository interfaces and connection pooling.

Python & Data Manipulation Language

Prerequisites for entry-level developer, automation, and data analyst roles.

  • Data Structures: Dictionary lookups, list comprehensions, tuples, and generators.
  • Core Libraries: Basic parsing with requests, tabular analysis with pandas, and JSON serialization.

Campus Aptitude & Reasoning Screening

First-round screening essentials across IT service firms (TCS, Infosys, Wipro, Cognizant, Accenture).

  • Quantitative: Percentages, Profit & Loss, Work & Time formulas, and Speed-Distance-Time conversions.
  • Logical: Seating arrangements, Syllogisms, Direction sense, and Blood relations.
